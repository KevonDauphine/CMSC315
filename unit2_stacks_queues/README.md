## My Reflection
During the course of the assignment, I learned how the concepts of LIFO and FIFO. Before I would do these things but now,
I can put a name to those concepts and communicate the gist of what I did to someone else when they ask how I solved a
problem. A challenge I ran into was reading the assignment and trying to comprehend it in my head, but by actually getting
to the coding part I was fully able to grasp these concepts. 

Stacks are LIFO, while Queues are FIFO. Meaning, with stacks
you remove the last element added, so the last element added is the first to go. While when dealing with Queues, the first element added is
removed. For example, You could use LIFO concepts as an undo button and for a game, you can use FIFO concepts for a turn
based game for turn order to remove the person who just had their turn.
